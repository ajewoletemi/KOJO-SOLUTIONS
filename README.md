## Deploy to GitHub Pages

1. Create a new repository on GitHub (e.g. `kojo-solutions`)
2. Upload all files in this folder to the root of the repository
3. Go to **Settings → Pages**
4. Source: Deploy from branch `main` (or `master`), folder `/ (root)`
5. Save. Your site will be live at `https://YOURUSERNAME.github.io/kojo-solutions/`

## Deploy to Render

1. Go to [render.com](https://render.com) and sign up
2. New → Static Site
3. Connect your GitHub repository
4. Build command: leave empty (or `echo "static"`)
5. Publish directory: `.` (root)
6. Create site. Render will give you a free `.onrender.com` URL.
